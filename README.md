# Datum

A build desk for engineering projects. Type what you are making, rank a fabrication route, save the checklist, and share it with a team.

**Bulldogs Build** is the Yale pack inside Datum: CEID, Wright Lab, YSoA, and the cores named on public Yale pages. Open shop is the same ranker for any makerspace, without pretending to know that lab's machines.

Not an official Yale system. Dollar amounts are retail estimates.

## Run

```bash
npm install
npm run dev
```

Accounts use email and password, plus Google or X where that sign-in is available. Saved projects and teams need the database migrations in `migrations/`.
