# Bulldogs Build

Yale fabrication planner for the Grokathon. Type a project idea and get a ranked shop path: machines, training, materials, and a build sequence from public Yale shop pages.

**Not an official Yale University system.**

## Demo

57-second walkthrough: [public/demo.mp4](public/demo.mp4)

## Run

```bash
npm install
npm run dev
```

Try the waterproof sensor brief, then **Generate 5 more briefs**.
